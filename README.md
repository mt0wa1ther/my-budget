💕 Совместные финансы
Умный учёт общего бюджета вдвоём — красиво, просто и на любом устройстве.

🌸 Что это такое
«Совместные финансы» — это лёгкое веб-приложение, которое помогает вам с партнёром вести общий бюджет: планировать расходы, записывать траты, контролировать перерасход и синхронизировать данные между устройствами. Все данные хранятся локально — ничего не утекает в интернет. 🔒

🚀 Как запустить
Совсем просто, ничего устанавливать не надо:

Открой ссылку на телефоне (или компьютере) — приложение работает прямо в браузере.
iPhone: Safari → «Поделиться» → «На экран "Домой"» → появится ярлык как у настоящего приложения.📱

Android: Chrome → «⋮» → «Установить приложение» или «Добавить на главный экран». 🤖
Готово! Открываешь ярлык — и пользуешься на весь экран, без адресной строки. ✨

⚠️ Для ярлыка и сохранения данных ссылка должна быть открыта по https (например, на GitHub Pages).

📖 Как этим пользоваться
Всё интуитивно, 4 шага:

💳 Доход — укажи сумму зарплаты 5-го числа и аванса 20-го. Можно складывать несколько сумм кнопкой «＋», чтобы учесть вклад обоих.
📋 План — настрой категории (Обязательные, Еда, Развлечения, Одежда, Внеплановые траты). У нужных категорий есть подкатегории (Квартира, Кредит, Подписки…), каждой задаёшь свой план.
✍️ Траты — записывай траты за день, выбирая категорию и подкатегорию. Всё попадает в «Дневник».
📊 Итог — автоматически видно: экономия или перерасход по каждой категории, общий баланс месяца.

🎯 Главные фишки
🗓️ Передавание месяца — кнопка месяца в шапке, переключение между 12 месяцами.
💸 Автоперенос остатка — остаток прошлого месяца переносится в новый автоматически.
🔄 Синхронизация кодом — поделись полным кодом (категории, планы, траты) со второй половинкой — данные объединятся, без QR-кодов и камеры. Просто, надёжно, офлайн.
📥 Резервное копирование — «Сохранить копию» / «Восстановить» файлом, чтобы ничего не потерять.
🔴 Сигнал перерасхода — суммы и шкалы подсвечиваются красным, когда превышен план.
📈 Живые шкалы — у каждой категории и подкатегории видно, насколько заполнен план.
🔔 Дисциплина — скрывай «Дневник» одной кнопкой, чтобы место не занимал.
🌸🌙 Две темы — нежная «цветочная» и ночная «лунная», переключаются в один клик.
🗑️ Защищённый сброс — полная очистка данных только по паролю, чтобы случайно не стереть.

⚙️ Технические детали
📌 Работает на iPhone и Android, а также в любом браузере.
💾 Все данные хранятся локально на устройстве (localStorage) — приватно и без интернета.
🔄 Синхронизация между устройствами — через обмен кодом или резервный файл.

💝 Ведите бюджет вместе — удобно, красиво и на одном языке!
